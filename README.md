# POI Digital

Iniciativa para repensar a reunião semanal do **POI (Planejamento Operacional Integrado)** da diretoria. O objetivo é sair dos relatórios impressos para uma experiência digital: visual, navegável, que funcione offline e se adapte a cada diretor.

> Fase atual: **descoberta**. O foco é entender pessoas, perguntas e restrições antes de desenhar telas.
